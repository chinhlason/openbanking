# TruongSonBank Mobile Demo

Native SwiftUI demo for Auth login.

Open `TruongSonBankMobile.xcodeproj`, run on iOS Simulator, then login with:

- Username: `84901234567`
- PIN: `739204`
- Auth URL on simulator: `http://localhost:8086/bff/api/auth/v1`
- Keycloak URL on simulator: `http://localhost:8088/realms/truongsonbank/protocol/openid-connect/token`
- Auth URL on real iPhone: `http://172.20.10.4:8086/bff/api/auth/v1`
- Keycloak URL on real iPhone: `http://172.20.10.4:8088/realms/truongsonbank/protocol/openid-connect/token`

For a real device, replace `localhost` with the Mac LAN IP.
